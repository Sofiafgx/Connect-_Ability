MODIFICATION GUIDE
------------------

To retrain with different parameters:
  • Edit train_model.py (line 69: fast_mode=True/False)
  • Edit exoplanet_model.py (n_estimators, max_depth, etc.)

To add new features:
  • Edit exoplanet_physics.py (add calculation methods)
  • Edit exoplanet_model.py (add to feature_cols list)

To customize output:
  • Edit exoplanet_predict.py (print_result function)
  • Edit batch_predict.py (results section)

To use different data:
  • Edit exoplanet_data_fetcher.py (data sources)
  • Provide custom CSV with required columns

BACKUP & PORTABILITY
--------------------

Essential files to keep:
  • exoplanet_model.pkl (trained model)
  • exoplanet_training_data.csv (training data)
  • All .py files (code)
  • requirements.txt (dependencies)

To move to another machine:
  1. Copy all project files
  2. Run: pip install -r requirements.txt
  3. Model ready to use (no retraining needed)

To retrain from scratch:
  1. Delete .pkl and .csv files
  2. Run: python3 train_model.py
  3. Wait 5-15 minutes for training
