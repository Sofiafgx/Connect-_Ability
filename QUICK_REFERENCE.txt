INSTALLATION
------------
pip install -r requirements.txt
python3 train_model.py              # First time only (5-15 min)

USAGE
-----
python3 exoplanet_predict.py        # Interactive mode
python3 batch_predict.py input.csv  # Batch processing

INPUT PARAMETERS
----------------
REQUIRED:
  - orbital_period (days)           Example: 365.25 (Earth)
  - transit_depth (ppm or %)        Example: 84 (Earth-like)
  - transit_duration (hours)        Example: 13.0
  - stellar_radius (solar radii)    Example: 1.0 (Sun-like)

OPTIONAL (with defaults):
  - stellar_mass (solar masses)     Default: 1.0
  - stellar_temp (Kelvin)           Default: 5778
  - snr (signal-to-noise)           Default: 10.0
  - stellar_magnitude               Default: 12.0

CALCULATED AUTOMATICALLY
------------------------
✓ Impact Parameter
✓ Semi-Major Axis (AU)
✓ Planet Radius (Earth radii)
✓ Equilibrium Temperature (K)
✓ Habitability Assessment

OUTPUT CLASSIFICATIONS
----------------------
CONFIRMED       - High-confidence exoplanet
CANDIDATE       - Potential exoplanet, needs follow-up
FALSE_POSITIVE  - Likely not a planet

TIPS
----
• SNR > 15: High quality, reliable
• SNR 7-15: Good for candidates
• SNR < 7: Use with caution

• Transit depth in ppm (>1) or fraction (≤1)
• Model auto-detects and handles both

• Confidence >80%: Very reliable
• Confidence 60-80%: Moderate
• Confidence <60%: Uncertain

PLANET SIZE CATEGORIES
----------------------
< 1.25 R_earth  - Earth-like (Rocky)
1.25-2.0        - Super-Earth
2.0-6.0         - Neptune-like
> 6.0           - Jupiter-like (Gas Giant)

TEMPERATURE ZONES
-----------------
< 200 K         - Frozen world
200-350 K       - Potentially habitable
> 350 K         - Hot world
