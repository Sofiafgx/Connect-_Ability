Welcome! This is a complete exoplanet detection and analysis system.

QUICK START (3 steps)
---------------------

1. INSTALL DEPENDENCIES
   $ pip install -r requirements.txt

2. TRAIN THE MODEL (first time only, 5-15 minutes)
   $ python3 train_model.py

3. MAKE PREDICTIONS
   $ python3 exoplanet_predict.py

That's it! Follow the prompts to analyze exoplanet candidates.

================================================================================

WHAT THIS SYSTEM DOES
---------------------

✓ Detects and classifies exoplanets using machine learning
✓ Trained on 15,775 NASA observations (Kepler, K2, TESS)
✓ Achieves 76.74% accuracy with ensemble of 4 ML algorithms
✓ Calculates impact parameter, planet radius, temperature, orbit
✓ Provides terminal-based input (no website needed)
✓ Outputs: CONFIRMED / CANDIDATE / FALSE_POSITIVE classification

INPUT (Terminal)
----------------
You enter 8 parameters:
  • orbital_period (days)
  • transit_depth (ppm or %)
  • transit_duration (hours)
  • stellar_radius (solar radii)
  • stellar_mass (solar masses)
  • stellar_temp (Kelvin)
  • snr (signal-to-noise ratio)
  • stellar_magnitude

OUTPUT (Terminal)
-----------------
System calculates and displays:
  • Classification: CONFIRMED / CANDIDATE / FALSE_POSITIVE
  • Confidence score (%)
  • Impact parameter (automatically calculated!)
  • Planet radius (Earth radii)
  • Equilibrium temperature (K)
  • Semi-major axis (AU)
  • Habitability assessment
